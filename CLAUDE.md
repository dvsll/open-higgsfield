# Studio agent brief

This repository contains Studio. Read `AGENTS.md`, then local `notes/studio.md` under "Where we left off" when available. Notes are personal and gitignored; fresh clones may not have them. Follow `RULES.md` for model and generation requirements, `DEADLINES.md` for competition checkpoints, and `PLAN.md` for scope.

Studio UI lives in `studio/`; supporting runtime, workflows and libraries live in `shared/`. Ad Studio is maintained in its own repository. There are no cross-project handoffs or automatic partner-sync hooks here.

Commit and push working changes on main as described in AGENTS.md. Keep Studio technical handoff notes current.
