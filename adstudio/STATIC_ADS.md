# Brand-aware static ads V1

Open `/adstudio/#brand`, open a saved brand and choose **Create an advertisement**, or **Use in ad** on a product card. Choose the correct original photograph, confirm its product association, select a concept, edit the live composition and **Export PNG**. Use **Create ad** in the header to reopen saved concepts. The preview uses the same deterministic SVG layout as the local PNG renderer; system font rendering can vary between machines.

Three layouts: product spotlight, editorial split and brand poster. Formats: feed1080x1350, story1080x1920, square1080x1080. Whole-photo/logo contain, never stretch or AI redraw. Name/palette/product/assets come from saved Brand DNA; saved tone/preferences can be reviewed, and a product description is inserted only on explicit request. Source-backed does not mean independently verified. No generated offers/prices/claims. Draft brands stay labeled.

Original asset IDs, concept edits, bounded undo/redo branches and immutable PNG export recipes/Blobs live in existing project/assets storage. `staticAds` is an optional version1 addition to project schema3; DB3/stores and all earlier projects/Composer histories remain compatible. Export images are retained in IndexedDB so missing runtime output files can fall back to saved PNGs. Source uploads are checked/recreated from saved references when needed. Storage failures remain explicit in the project bar.

Optional supporting imagery uses **OSH.keyframe -> shared /api/keyframe -> Comfy SDK -> proxy -> existing Z-Image workflow** and shared installed-model discovery. It is disabled without verified runnable weights/nodes. No model downloads, new inference provider, product/logo regeneration or automatic GPU calls. Tested machine: ComfyUI offline, optional real generation NOT RUN.

Actual local examples: `/adstudio/#static` -> **Open No Crumbs ads**. This imports three editable concepts, real exported PNG histories and authentic original logo/photo into a separate example project/brand; existing projects and prior edits are kept. Private evidence: `outputs/static-ads-demo/index.html`, three numbered PNGs, `verification.json`, `fidelity-audit.json`, `storage-evidence.json`. Product is photo-only: no SKU/quantity/ingredients inferred. Palette is based on saved website CSS candidates and still needs customer approval. PNG source hashes are unchanged; resampling changes output pixels, so no pixel-perfect fidelity claim.

Reproduce with the existing isolated Node22.20 runtime: run `adstudio/scripts/static-demo.mjs`, then `static-demo-verify.mjs`; existing Pillow can run `static-audit.py` for offline resampling measurements. These use production upload/export APIs, FFmpeg only to prepare the private test reference, and no generation. Source photos and evidence are gitignored.
